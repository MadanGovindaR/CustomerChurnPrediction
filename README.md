# Customer Churn Prediction System

## Overview
This project predicts whether a customer will leave a company or continue using the service using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- NumPy

## Features
- Customer churn prediction
- Machine learning classification
- Streamlit frontend application
- User-friendly interface

## Dataset Features
The dataset contains:
- Age
- Monthly Bill
- Contract Years
- Support Calls
- Internet Usage

## Machine Learning Algorithm
- Logistic Regression

## How to Run the Project

### Install Required Packages
pip install pandas numpy scikit-learn streamlit

### Train the Model
python train_model.py

### Run Streamlit App
streamlit run app.py

## Example Prediction
